# LinguagemDeProgramacaoDois

Repositorio destinado as entregas da disciplina Linguagem de Programacao II.

## ExPrecipitacao

Projeto Java/Maven que le um arquivo CSV com registros diarios de precipitacao da FUNCEME
e calcula estatisticas anuais e mensais para a cidade de Acarau/CE.

### Executar

```bash
cd ExPrecipitacao
mvn test
java -cp target/classes Main
```
